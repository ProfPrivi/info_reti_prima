### Obiettivi del Modulo 2
In questa seconda unità alleniamo il **Pensiero Computazionale**: impariamo a trasformare un problema reale in una procedura logica rigorosa, chiara ed efficiente, prima ancora di scrivere codice testuale.

### Mappa del Percorso
| Lezione | Tema Centrale | Concetti Chiave |
| :--- | :--- | :--- |
| **2.1** | Pensiero Computazionale | Problem solving, astrazione, modello, le 4 proprietà dell'algoritmo |
| **2.2** | Coding Visivo e Selezione | Diagrammi di flusso, variabili, tipi di dato, blocco `Se` (Rombo) |
| **2.3** | L'Iterazione (Cicli) | `Per`, `Mentre`, `Fai`, contatori, accumulatori, sentinelle, tracciamento |
| **2.4** | Teoria ed Efficienza | Teorema di Böhm-Jacopini, correttezza vs efficienza, Ricerca Lineare vs Binaria |
| **2.5** | I Vettori (Array) | Indici `0..N-1`, omogeneità, scansione con `Per`, *Index Out of Bounds* |
| **2.6** | Sottoprogrammi | Procedure vs Funzioni, parametri (valore/riferimento), scope e *Call Stack* |
| **2.7** | Dalla Grafica al Testo | Ponte dai blocchi di Flowgorithm alla sintassi del linguaggio Python |
