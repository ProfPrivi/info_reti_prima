### Obiettivi del Modulo 3
In questa unità passiamo dalla logica visiva dei diagrammi di flusso a un vero linguaggio professionale: **Python**. L'approccio in aula privilegia la comprensione **architetturale e teorica** di come il linguaggio gestisce la memoria, il flusso di controllo, le strutture dati, le funzioni e gli errori.

### Mappa del Percorso
| Lezione | Tema Centrale | Concetti Chiave |
| :--- | :--- | :--- |
| **3.1** | Modello Esecutivo | Bytecode, PVM, CPython, REPL vs Script, IDE |
| **3.2** | Tipi e Memoria | Oggetti ed etichette, tipizzazione dinamica/forte, casting, operatori `//` e `%` |
| **3.3** | Decisioni e Logica | `if / elif / else`, indentazione PEP 8, `and/or/not`, *short-circuit* |
| **3.4** | Iterazione | `while`, `for`, `range()`, `break`, `continue`, clausola `else` |
| **3.5** | Liste | Array dinamici, indici negativi, slicing, mutabilità, `enumerate()` |
| **3.6** | Strutture Avanzate | `tuple` (immutabilità/unpacking), `set` (insiemi), `dict` (tabelle hash) |
| **3.7** | Funzioni e Scope | `def`, `return`/`None`, riferimento all'oggetto, regola LEGB, moduli |
| **3.8** | Errori e Qualità | Sintassi vs Runtime vs Logica, `try/except`, principio DRY e *edge cases* |
